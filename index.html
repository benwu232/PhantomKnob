04 / PRINCIPLE

运行原理

如果你是技术极客，下面是PhantomKnob背后的原理。

1 · 识别目标控件

鼠标悬停在屏幕上时，通过调用系统api识别鼠标下方的app和控件。

2 · 拦截/屏蔽系统默认手势

避免新手势和旧手势发生冲突。

3 · 构建旋钮

获取触点坐标，使用创新算法构建旋钮并计算其参数（包括旋转的角度，旋钮的直径等）。

4 · 映射事件

把旋钮的变化映射为相关控件支持的事件（如方向键、鼠标滚动、两指滑动等）。

5 · 发送事件

把事件插入操作系统事件流。

05 / TRUST

安全与隐私

权限、隐私与分发渠道，每一个决定都经得起追问。

为什么不上架 App Store？

因为使用了 Apple 的非公开 API 并拦截系统事件，所以无法上架——BetterTouchTool 等同类软件面临同样的取舍。但不在 App Store 不等于没有审核：安装包已通过 Apple 公证（Notarized），每个版本都经过 Apple 的恶意软件扫描。

为什么要辅助功能权限？

MacOS 对"一个 App 能看见并操作另一个 App"管控极严，辅助功能 API 是唯一的正规通道。PhantomKnob 用它做且只做三件事：读取悬停位置的控件、拦截触控板手势、发送调节事件。权限在技术上"能"读键盘，与 PhantomKnob "在读"是两回事——拦截范围仅限手势事件，不监听、不记录任何键盘输入，处理全程在本机。

安全可靠 · 注重隐私

PhantomKnob 无账号、无广告，完全离线可用，运行时不收集任何数据；授权校验全部在本地完成，崩溃报告可在设置中关闭。
