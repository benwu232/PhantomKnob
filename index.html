05 / PRINCIPLE

How It Works

For tech enthusiasts, here is what happens under the hood.

1 · Detect Target Control

Queries accessibility APIs under the mouse cursor to identify the target application and UI element.

2 · Suppress Default Gestures

Prevents conflicts with native macOS trackpad gestures during active knob rotation.

3 · Construct Virtual Knob

Captures multi-touch coordinates and calculates angular displacement, radius, and rotation delta with proprietary algorithms.

4 · Map to Target Actions

Translates angular changes into target-compatible events (wheel delta, arrow keys, continuous steps).

5 · Inject Event Stream

Injects synthetic events into the macOS event stream as native hardware input.

07 / TRUST

Security & Privacy

Permissions, privacy, and distribution — transparent by design.

Why Not on the App Store?

PhantomKnob uses Apple private multi-touch APIs and intercepts system events, making App Store distribution impossible (same as BetterTouchTool). However, the app is fully Notarized by Apple and scanned for malware.

Why Accessibility Permissions?

macOS strictly restricts apps from inspecting or controlling other windows. Accessibility API is the only standard channel. PhantomKnob only uses it to read hovered controls, intercept gestures, and inject events. It never logs or monitors keyboard input, and all processing is 100% on-device.

Private by Design

No accounts, no ads, completely offline. No tracking or telemetry collected. License checks run locally, and crash reports can be turned off in Settings.
