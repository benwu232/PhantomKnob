旋钮 Overlay UI (V2 - 去除中心指针设计)

根据你的反馈，我们去掉了旋钮中心的直线指针（以防影响中心倍数值的视线）。现在你可以测试三种代替内部指针的旋转反馈方案。

选择你倾向的“非指针”旋转反馈机制

方案 A：外周刻度小圆点 (Rim Indicator Dot) 推荐

A

保持中心完全空白，仅在圆形 Overlay 外边缘的圆环轨道上显示一个发光小圆点。小圆点随手指角度旋转，清晰指示旋钮朝向，同时不对任何文本造成干扰。

方案 B：外围刻度线整体转动 (Rotating Tick Ring)

B

在圆形外围绘制一圈极细的刻度线。旋转手势时，整圈刻度线随角度同步旋转（其中一根刻度线加粗/加亮以作为主刻度）。有非常强的机械齿轮咬合感。

方案 C：极简弧线充能 (Dynamic Radial Arc)

C

没有单独的旋转指标。仅有一根沿着外侧圆环生长的进度弧线，弧线的起始位置或长度直接与数值绑定。视觉上最为扁平和现代，类似智能手表的环状图表。
