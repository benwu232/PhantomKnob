如何激活旋钮定制？(How to Activate Customization)

头脑风暴：选择最适合的用户交互入口

A

HUD 悬浮窗直接激活 (推荐)

在旋转手势激活、显示悬浮 HUD 时，提供交互直接进入定制。

🔊 音量滑块下悬浮圈 右键 / 快捷键 ⌘E
直接在光标处弹出迷你设置面板，定制本控件的颜色、映射等。
B

控制面板 (KnobPanel) 集中配置

在控制面板（双击状态栏或 ⌥Space 唤起）中新增“自定义规则”配置项。

KnobPanel 控制面板 -> 规则列表
• QuickTime Player - 进度条 [编辑]
• 剪映 - 时间轴 [编辑]
• [+ 新增自定义规则] (需在屏幕上手动点选或录入)
C

状态栏菜单快捷触发

在 macOS 顶部状态栏下拉菜单中，添加一个侦测并创建规则的选项。

顶部状态栏 ◉ -> 为当前光标下控件创建规则...
点击后自动捕捉鼠标下的 AX 控件，弹出独立配置窗口。

对比与分析

  • 方案 A (HUD 直接激活)：最符合直觉。在使用手势时，发现不好用或想改颜色，直接右击或 ⌘E 即可在原地定制，上下文不丢失。
  • 方案 B (集中配置)：适合全局管理与导出。但新建规则时，用户需要手动选择 App 甚至抓取 UI，流程较繁琐。
  • 方案 C (状态栏菜单)：实现简单，但使用时需要先将鼠标悬停到目标控件，再移动手势去顶部状态栏点击，容易偏离目标。
