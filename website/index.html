FAQ

Frequently Asked Questions

Have questions about Phantom Knob? Find answers to commonly asked questions below.

How does Phantom Knob capture trackpad rotations?

Phantom Knob binds directly to macOS Multitouch APIs to monitor raw finger coordinates. By analyzing spatial configurations and touch dynamics, it identifies circular rotation gestures with high accuracy and feeds translation commands back into focused application window coordinates.

Is accessibility permission secure?

Yes. Phantom Knob uses Accessibility API permissions strictly to detect elements under the cursor and post scroll wheel or key events for slider control. Your gesture input data is processed entirely locally on your machine and is never transmitted online.

What happens when the 15-minute free session expires?

When the session limit is reached, Phantom Knob automatically turns off control mode. There is no penalty, cooldown, or fee—you can instantly reactive it via the menu bar or by pressing the hotkey combination (⌥⌘R) again to start a new session, introducing only a brief activation delay.

Can I build rules for custom apps?

Yes! Simply hover your cursor over any custom UI slider, press the customization hotkey (default is C), and choose from the overlay layout configurations to assign appropriate mappings for immediate control.
