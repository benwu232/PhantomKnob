# 旋钮定制面板原地锁定真实操作设计 (WYSIWYG 升级版)

## 背景与目标

在前期开发中，我们实现了定制面板（`CustomizerHUDView`）的虚拟预览区。然而，虚拟预览存在以下局限性：
1. **真实度偏差**：用户在 180px 的局部预览窗口内旋转，无法直接感受外部目标应用（如 Final Cut Pro 调色、Logic Pro 阻尼）的实际运行速度与手感。
2. **位置脱节**：配置面板与物理手势操作脱离，一边调试参数，一边看虚拟预览，体验分裂。

**目标：**
舍弃面板内部的虚拟预览区，改为**原地锁定并直接操作物理旋钮**。
- 用户按下 `C` 键时，真实的 Overlay 在原地被固定锁定，旁边弹出配置面板。
- 用户调节滑块（半径、倍率、渐变色），屏幕上的真实旋钮大小、渐变色会**即时响应响应刷新**。
- 用户直接在触控板上旋转物理两指，便可触发真实的 macOS 滚轮或按键，**边调边感受真实手感**。

---

## 总体布局与交互避让

### 1. 面板尺寸与避让坐标计算
- 移除顶部的 `previewArea` 预览容器，面板高度上限由 `680px` 大幅精简收缩为 **`480px`**，整体形态更精致，有效防止阻挡屏幕工作流。
- **动态避让算法**：当弹出定制面板时，根据当前锁定的旋钮中心坐标（`fixedCenter`），将定制面板优先放置于其**右侧 130px 处**；如果右侧空间不足溢出屏幕，则自动镜像放置到**左侧 130px 处**；并在垂直方向上与 Overlay 的中心对齐。

```
                    ┌────────────────────────────┐
                    │  ×  Edit Control Rule      │  ← ① 顶栏（含显式关闭按钮）
                    ├────────────────────────────┤
 ┌───────────┐      │  [单旋钮] [双环] [无级变速]  │  ← ② 类型选择器
 │           │      ├────────────────────────────┤
 │  ◎ 真实   │ 130px │  🎨 外观                   │  ← ③ 外观参数（大小/颜色）
 │   旋钮    │─────>│  (调节后屏幕旋钮等比缩放)  │
 │ (原地锁定) │      ├────────────────────────────┤
 └───────────┘      │  ⚡ 行为                   │  ← ④ 行为参数（输出/倍率）
                    │  (调节后手指操作反馈热更新)  │
                    ├────────────────────────────┤
                    │  ▶ 高级信息（默认折叠）     │  ← ⑤ 元素定位标识
                    └────────────────────────────┘
```

### 2. 底部滚动指示蒙层
为了给用户提供清晰的界面滚动视觉暗示（当小窗在 480px 高度内未展齐所有滑块时），在 ScrollView 容器最底端叠加一个向上淡出（高度 `12px`）的**半透明羽化渐变阴影蒙层**。
- 该阴影悬浮于 ScrollView 之上，文字和滑块在滑向底部时会自然隐入阴影，直观暗示下方仍有隐藏参数。
- 蒙层设置 `allowsHitTesting(false)`，不影响触碰和滑动操作。

## 核心交互行为

### 1. 状态机手势锁定与穿透
在 `KnobStateManager.swift` 转换到 `.customizing` 状态时：
1. **锁定物理中心**：固定 `fixedCenter`，物理手势的滑动不再改变 Overlay 在屏幕上的绝对位置，旋钮原封不动停在原处。
2. **手势物理穿透**：当两指再次在触控板上旋转时，状态机完整触发角度计算与倍率换算，直接通过 `InputTranslator` **向系统下发真实的鼠标滚轮或键盘虚拟事件**。
3. **手指离开常驻**：手指离开后，由于自定义状态仍在，Overlay 不触发 `fadeOut()`，保持常驻。

### 2. 关闭与状态解锁
- 配置面板左上角提供 `Close (X)` 关闭按钮，面板也监听 `Esc` 或再次按下 `C` 键。
- 触发关闭时，调用 `CustomizerHUDWindowController.shared.hide()`。
- 隐藏面板时向状态机发布 `KnobPanelDidHide` 通知，状态机收到后解锁 `customizing` 状态退回为普通模式，真实 Overlay 自动淡出消失。

### 3. 参数即时热重载刷新
- 定制面板中滑块 `onChange` 时自动执行 `save()` 并写入 `RuleLibrary`。
- `KnobStateManager` 自动监听到重载事件，如果是 customizing 模式，立刻调用 `overlayController.update()` 刷新屏幕上常驻锁定的真实 Overlay 的渲染属性（颜色、外圈半径、内圈半径、类型）。

## 涉及文件变更

| 文件 | 变更内容 |
|------|---------|
| `View/CustomizerHUDView.swift` | 移除预览区 `previewArea` 与相关的本地拖拽与触控手势逻辑；在顶栏增加关闭按钮，在底部 ScrollView 下方增加滚动淡出蒙层。 |
| `View/OverlayView.swift` | 保持上一版修改所得的基于毫米的 `minRadius`/`maxRadius` 渐变边界支持。 |
| `Service/CustomizerHUDWindowController.swift` | 增加 `overlayFixedCenter` 属性并在 show 时接收传参；将高度重置为 480px，并根据中心执行左右镜像避让放置算法。 |
| `Service/KnobStateManager.swift` | 在 enterCustomization 时向 HUD 传入当前的 fixedCenter；在 customizing 状态下允许手势角度和 Translator 穿透计算，在 rule 重载时触发 Overlay 的视觉实时重绘。 |
